# DC Crypto Miner 360

Panel personal para registrar oportunidades y resultados relacionados con criptoactivos y USDT.

## Estado actual
Esta primera versión es un **panel de seguimiento**, no un minero. USDT es una stablecoin y no se mina directamente. El sitio no genera ingresos, no ejecuta minería en el teléfono y no mueve fondos.

## Seguridad
- No introduzcas contraseñas, frases semilla, claves privadas ni secretos API de Binance.
- Nunca habilites permisos de retiro para una API.
- Comprueba costes, comisiones, electricidad y riesgos antes de usar cualquier servicio.
- Los datos de esta demo se guardan localmente en el navegador del dispositivo.

## Publicar
Se puede desplegar como sitio estático en Render usando este repositorio y la carpeta raíz.
